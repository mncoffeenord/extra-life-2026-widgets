# local-assets

Files in this folder are git-ignored (except this README). Put local-only art here.

- `overlay-preview.png` (1920x1080): a flattened export of your overlay. If it exists, `/preview`
  draws it behind the widgets. If it is missing, `/preview` draws plain boxes in the same positions.
- `overlay-preview-messages.png` (optional): the same with the taller Donations box (rail variant for the
  with-messages widget). Used when `/preview` is set to **Donations box: With messages**; if it is missing, the
  taller box is drawn over `overlay-preview.png`.

The overlay art includes Extra Life / Children's Miracle Network branding, so it is not committed to this public repo.
